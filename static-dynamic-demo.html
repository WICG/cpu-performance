CPU Performance API — Static/Dynamic Example

  • A web application considers applying some effect that improves UX but requires excessive computation power.
  • It uses the CPU Performance API to determine statically if the user device is powerful enough. The effect will be available only if the device's tier is at least 3.
  • It also uses the Compute Pressure API to dynamically monitor device usage. The effect is enabled if usage state is nominal or fair, and disabled if it is serious or critical.
